## How this was generated

1. Load `backend/content/games.json`, pull every scenario in game `g1`.
2. For each scenario, pick one of the three options (a spread of
   intended-strong and intended-weak picks).
3. Build a system prompt from the nutrition team's 2026-11-06 feedback
   (Scoring and Feedback, Q3).
4. Call TAMU AI (default chat model) with that system prompt plus the
   scenario and the student's chosen option.
5. Write this Markdown file.

No student records are used — the script does not read any Mongo
collection. The TAMU API key is loaded from `backend/.env` and never
printed or persisted.
