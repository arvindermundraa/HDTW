# 1. Week 1 example goals

**Source:** `backend/content/weeks/week1.json`, step `goal_and_plan.examples`.

Context: Week 1 ends with the student setting a small, specific goal and
plan. These are the example pairs the app currently seeds for each focus
area — one goal and one when/where plan per area. The student can edit or
replace them; the examples only appear as a starter.

The team asked where to see these (Week 1 Content, Q3). They are listed by
focus area below. Not marked DRAFT — this copy has been in the code since
Week 1 shipped — but the team is welcome to replace any item.

## Goal prompt copy

The student types their goal into two free-text fields, up to 200 characters
each. Prompts used on screen:

1. Goal prompt: **"I will…"** (placeholder: *A behavior you want to try, in
   your own words*)
2. Plan prompt: **"When / where will you try it?"** (placeholder: *The
   moment this will happen*)

Each example above drops into those two fields as a starting point.
